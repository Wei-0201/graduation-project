# V5 學習路段階段與近遠目標

目前狀態：標註工具與離線訓練流程已備妥，尚未收到六類新標註；沒有訓練或部署此功能。

## 標註

開啟 `labeling/label_path_v5.html`，或使用本機伺服器頁面。
120 張圖從 V2、V3、V4 的 15 次 AUTO 行駛抽出，包含進彎及較後段畫面。
不要把已跑出車道的畫面誤標成「即將回直線」。無法判斷請略過。

六類：直線、即將左彎、正在左彎、即將右彎、正在右彎、即將回直線。
另可選不確定；這個標記不會作為第七種路段去訓練。
近處 y=180、遠處 y=120 的中央點可選填，不會自動用舊模型產生假標籤。
只選階段也能訓練階段分類器；未標中央點的照片不提供中央位置的監督。

## 收到 JSON 後

使用 model_centering 的既有 .venv，不必在 Jetson 安裝訓練環境：

    .\.venv\Scripts\python.exe learned_path_v5\train_path_stage.py PATH_TO_JSON --validate-only
    .\.venv\Scripts\python.exe learned_path_v5\train_path_stage.py PATH_TO_JSON --epochs 20

先查類別分布與中央點數量。缺少轉彎尾端的真實畫面時，需要補拍，不能憑空學會。
訓練最少需要每類 3 張訓練、1 張驗證才能開始；此門檻只是防止空類，不表示資料足夠。
預設保留四次完整行駛供驗證；鏡像增強在分組之後進行，左右階段與 X 一起反轉。

ResNet18 共享骨幹，輸出近處 X、遠處 X、六類路段 logits。
使用既有模型骨幹初始化；新的階段頭與兩距離輸出頭需由人類標註訓練。
維持既有 BGR/ImageNet 前處理。輸出為 CPU legacy state_dict，旁附模型規格與驗證記錄。
指標包含即將進彎被誤認為正在彎中的次數、出彎辨識率、近遠 X 誤差。
驗證集用於選模型，並非獨立最終測試。

## 部署限制

V5 的八輸出權重與舊 XY 二輸出程式不相容，不能直接替換目前 Jetson 模型。
新階段與目標頭尚未訓練，沒有提供車控啟動器。
收到標註後需檢查各類與近處位置標註覆蓋、實際重播，再整合控制策略。
階段辨識本身不等於已校準的轉向；尤其不能把「正在左彎」當成固定左轉角。
整合時仍需考慮近處路徑、偏移與方向修正，並做低速實測。
