# 模型車道置中整合版

這份 Jetson 程式以 `train_model.ipynb` 訓練的 ResNet18 預測目標點 `(x, y)`；直接以模型輸出的正規化 `x` 產生 `DRIVE,speed,turn`。`x` 在畫面右側時送負轉向（右轉），左側時送正轉向（左轉）。`y` 顯示在畫面與狀態中，並用於檢查預測點是否在影像內；不直接換算成轉向角。AUTO 速度固定為 0.12。Jetson 不再另外把模型轉向限制為 ±0.5；有效影像範圍本身使轉向介於 -1 與 +1。ESP32 保留指令範圍、馬達 PWM 範圍與失聯停車。

原本的黑線擷取、線段擬合及其畫面標記只供顯示與診斷；不計算車道中心，也不參與 AUTO 轉向或啟停判定。模型輸出超出影像範圍或畫面逾時時，AUTO 會送 `STOP`，等待新的有效預測。模型沒有輸出車道存在與否的可信度，因此即使預覽沒有取到線，只要模型預測點有效，AUTO 仍可能行駛；測試時須特別注意這項限制。

## 需要的檔案

- `jetson_model_centering.py`：放在 Jetson Nano。
- `collect_xy.py`：有圖形桌面時，用相機畫面點選目標位置，直接建立 `dataset_xy`。
- `collect_xy_web.py`：只有終端機時，在 Jetson 啟動後從同網路的電腦瀏覽器拍照、點選目標位置。
- `train_model_ready.ipynb`：由你提供的訓練筆記本複製並修正資料夾檢查、翻轉開關、驗證集增強與 CPU/GPU 裝置選擇。
- `best_steering_model_xy.pth`：執行 `train_model.ipynb` 訓練後產生，放在同一目錄或用 `--model` 指定完整路徑。這次提供的檔案中沒有這份權重，不能直接執行模型推論。
- `esp32_centering_v11.ino`：配對的 ESP32 程式。保留 `READY CENTERING V10` 回覆字串，因為 Jetson 握手檢查的是這個字串。與原貼上的 ESP32 程式相比，僅將失聯停車時間改為 500 ms。

Jetson 需安裝與 Jetson 系統／JetPack 相容的 PyTorch、torchvision，以及 OpenCV、Pillow、NumPy、Flask、pyserial。訓練影像與車上相機應採相同安裝方向及視角。筆記本的輸入前處理是 PIL 縮放至 224×224、RGB 轉 BGR 通道後以 ImageNet 數值正規化；整合版逐步照做。

## 模型是否需要訓練

如果已有與這台車的相機視角、路線相符的 `best_steering_model_xy.pth`，可以直接使用；否則需要先訓練。`train_model.ipynb` 讀取 `dataset_xy/*.jpg`，從檔名的第 2、3 個底線分隔欄位讀取目標點像素座標，例如 `frame_160_120_0001.jpg` 表示 `(x=160, y=120)`。每張圖需要標註車子應朝向的目標點；影像須來自實際車載相機，包含直線、左右彎、不同位置與光照。執行訓練後應取得 `best_steering_model_xy.pth`。筆記本固定使用 CUDA，沒有 CUDA 的訓練電腦須修改裝置設定。

可在有圖形桌面的 Jetson 上先執行 `python3 collect_xy.py --camera 0 --output dataset_xy`。將車子斷開馬達電源並以手移動到不同位置、角度；每次對畫面前方的期望路徑中心按滑鼠左鍵，即儲存一張未畫標記的 `xy_x_y_識別碼.jpg`。按 `Q` 結束。把 `dataset_xy` 與 `train_model_ready.ipynb` 放在同一目錄，在 Jupyter 逐格執行筆記本；訓練完成後將權重檔放在 Jetson 的程式目錄。

若只有終端機，在 Jetson 的程式目錄執行 `python3 collect_xy_web.py --camera 0 --output dataset_xy --port 5001`，再用同網路的電腦瀏覽器開啟 `http://JETSON_IP:5001`。每次先按「拍一張」，再點照片的路徑目標；照片會存到 Jetson 的 `dataset_xy`。收集完成後在終端機按 `Ctrl+C`。

## 執行

```bash
python3 jetson_model_centering.py --model ./best_steering_model_xy.pth --port /dev/ttyUSB0
```

先使用 `--image /path/to/frame.jpg --output /path/to/debug.jpg` 離線確認紫色模型目標點、黑線與左右方向；或用 `--video /path/to/video.avi` 檢查整段影片。兩種離線模式都不會開啟馬達序列埠。接著讓車輪離地，檢查 `DRIVE` 的正負值是否讓車輪朝預期方向差速，再低速實地測試。

`train_model.ipynb` 的 `random_hflips=False` 參數目前沒有控制翻轉：資料集程式仍有 50% 機率翻轉每張圖。若車道或目標點左右不對稱，應先修正該訓練程式並重新訓練。
