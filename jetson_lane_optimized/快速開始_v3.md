# v3：Jetson＋ESP32 低速起步版

這次兩邊都要更新。ESP32 開啟 `esp32_soft_start/esp32_soft_start.ino`，選你原本的開發板與連接埠燒錄；關閉 Arduino 序列監控視窗後，Jetson 換成同包的 `jetson_car.py`：

```bash
python3 jetson_car.py --port /dev/ttyUSB0
```

先停止原本 Jetson 程式。網頁依然是 Jetson IP 的 5000 埠。畫面底部顯示 v3；串口啟動顯示 `READY ESP32 SOFT START V3`。

## 起步與加速

- 偵測連續有效 3 幀才開始；speed 從 0.12 開始，至少維持 1 秒。
- OFFSET 絕對值不超過 10 像素、steering 不超過 7、偏移變化率不超過 25 px/s，持續 0.8 秒後才加速。
- 每秒增加 0.03，最高 0.24；完全穩定時，起步後約 5 秒到最高命令值。
- 一旦不穩定，命令回到 0.12；ESP32 以較快的下降斜率降低 PWM。失線／影像逾時直接 STOP，重新抓線也重新低速起步。
- 保留 v2 抓線、自動選控制高度與延伸線。

ESP32 預設關閉原本會立刻輸出左135／右130的起步 Kick。PWM 從 0 開始，每秒最多上升 100，約 1 秒到原本的最低運轉 PWM。STOP 不走緩降，收到後直接 PWM=0。方向反轉先清零並等待120ms。Kick 開關若手動開啟，亦採非阻塞與 PWM 緩升，不會重現原本的立即高脈衝。

## 保留的設定與實際速度限制

馬達腳位、A相RISING計數、每圈左143／右147、基準左115／右110、最低左100／右95、轉向增益0.18、最大修正10均保留。不是尚未校正的雙輪 RPM PI；編碼器仍用於 RPM 顯示與穩定直行時的左右輪同步。

速度現在映射為以下基準 PWM（還沒加轉向與同步修正）：

| speed 命令 | 左 PWM | 右 PWM |
|---:|---:|---:|
| 0 | 0 | 0 |
| 0.12 | 100 | 95 |
| 0.18 | 105 | 100 |
| 0.24 | 110 | 105 |
| 0.30（手動） | 115 | 110 |

所以這次加速確實改變 PWM；數字不是 m/s，RPM 未校正，因此不保證線性實際車速。因沿用你的最低 PWM，穩態起步的100／95仍和舊版最低值相同，主要先解決瞬間Kick及加速時機。若穩態仍太快，需要實測最低可轉PWM或改齒比／RPM閉迴路，不能只把0.12改得更小。

先架空確認左右轉向與STOP，再從車道中央測試。如果關閉Kick後其中一輪不動，立刻STOP，分別校正該輪最低可運轉PWM；不要讓卡住的輪子長時間通電。

通訊中斷500ms由ESP32停車；手動網頁心跳中斷600ms由Jetson停車。PI尚未啟用。首次實車測試仍需要確認相機對正、馬達左右接線與實際最低PWM。
